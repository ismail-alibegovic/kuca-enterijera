# Proposed logo treatment (NOT approved)

Concept proposal for a modernised Kuća Enterijera identity. The original logo is untouched in `../original/`.

- `mark-duo.svg`: primary mark (ink + natural oak)
- `mark-mono.svg`: single-colour version
- `mark-solid-small.svg`: solid version for favicons and sizes under 24 px

The wordmark is set in Instrument Sans (SIL OFL) uppercase with 0.2em tracking. The accent on "Ć" is replaced by the
leaf, a nod to the original logo. Before production use, outline the wordmark into vector paths
and run a trademark/clearance check.
