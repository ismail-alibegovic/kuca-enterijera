# Fonts

**TeX Gyre Heros** (regular + italic), by the GUST e-foundry, released under the
[GUST Font License](https://www.gust.org.pl/projects/e-foundry/licenses) (a free license based on the LPPL;
use, embedding and redistribution are permitted).

- Source: https://www.gust.org.pl/projects/e-foundry/tex-gyre/heros (qhv2.004otf.zip)
- Converted to WOFF2 and subset to Latin + Latin Extended-A (incl. č ć đ š ž), punctuation and €.
- Chosen because it is a faithful, legally free Helvetica-style grotesk, the closest licensable match to
  the Swiss sans of the design reference. Only the regular weight is used; italic is for single accent words.
